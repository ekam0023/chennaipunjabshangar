# Chennai Punjab Shangar (Next.js)

Tap / click / press Space anywhere to make the character jump. Count is saved in the browser.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

The 3D model and photo texture are in `public/model.obj` and `public/photo.jpg`.

## Jump sound

Put your voice clip at `public/jump.mp3`. It plays on every jump (nothing plays if the file is missing).
